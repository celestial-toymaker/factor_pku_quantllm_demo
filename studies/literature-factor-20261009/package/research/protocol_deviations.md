Two repairs were necessary. Neither introduced a candidate, sign, horizon, universe, benchmark or performance-based replacement.

1. **Historical diagnostic labels, before finalist freeze.** Version 1 retained positive stale opens at suspended forward-label endpoints. The portfolio simulator already rejected suspended fills. Version 2 masks those label endpoints, preserves the first run and its source, and declares prior exposure in the corrective freeze. All six primary account results, turnover and score-overlap fields matched exactly after repair. Both complete historical versions were reproduced in a fresh environment; version 2 supplies the submission metrics.

2. **Final acquisition gate, before any final portfolio calculation.** The first acquisition downloaded 300 histories successfully, then the integrity audit found an unrecorded Yunnan Baiyao cash distribution. The provider dividend response omitted the special dividend. [Issuer announcement 2026-31, published September 17](https://epaper.cs.com.cn/zgzqb/html/2026-09/17/nw.D110000zgzqb_20260917_6-B026.htm) supplies cash of CNY1.038 per share, September23 record date and September24 ex/payment date, with no bonus shares. A separately labeled supplementary CSV supplies these facts; the provider original and every market-quote byte are preserved.

The initial implementation reserved its exclusive marker before data acquisition, so it blocked a data-only continuation as well as repeat portfolio tests. The failed marker, audit, fingerprint and metrics were archived under `research/final_acquisition_gate/` rather than erased. A guarded recovery verified that no final capability read, account evaluation or IC had occurred, validated the corrected data, and allowed the original frozen entry point to resume. This is an operational deviation from the implementation's stricter one-attempt wording, disclosed here; the user's single **portfolio evaluation** budget is preserved. The frozen code and finalist hash did not change. The access log records both acquisition reservations and the sole subsequent portfolio-data read.

The action was publicly announced before the first permitted signal. The raw final prices had already been inspected by the automated data audit, so no claim of an unseen sample is restored. The independently downloaded period was also partly exposed through earlier student research. Final performance cannot change the method or erase failed validation.
